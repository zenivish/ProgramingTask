## Materi

Repository ini mencakup materi dan latihan Java yang dipelajari selama beberapa minggu, antara lain:

* Dasar-dasar pemrograman Java
* Input dan output
* Tipe data dan variabel
* Operator
* Percabangan `if`, `if-else`, dan `nested if`
* Struktur pemilihan
* Operator ternary
* Perulangan
* Penggunaan `String`
* `Scanner`
* Penyelesaian masalah menggunakan Java
* Praktikum dan tugas berdasarkan jobsheet

> Materi dapat bertambah sesuai dengan pertemuan dan tugas yang diberikan selama perkuliahan.

## Isi Setiap Folder

Setiap folder `minggu1` sampai `minggu6` berisi source code dan file pendukung sesuai dengan materi atau tugas pada minggu tersebut.

Masing-masing folder memiliki `README.md` untuk memberikan penjelasan lebih spesifik mengenai:

* Materi yang dipelajari
* Soal atau studi kasus
* Source code
* Penjelasan program
* Contoh input dan output
* Dokumentasi atau screenshot jika diperlukan
